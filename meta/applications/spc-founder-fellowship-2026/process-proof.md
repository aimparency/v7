# SPC application as an Aimparency run

This is a compact run record, not a claim that generating an application with AI
is novel. It documents the narrower proposition that durable human intent can
guide replaceable AI executors through consequential work while keeping human
authority explicit.

## Objective

`b52d435e-72b5-4839-b0cd-fbc916b46a03`  
Create and submit an exceptional SPC application for Aimparency.

The objective is connected to two missions:

- obtain real funding and institutional support;
- test Aimparency as an intent layer for autonomous AI.

It is committed to the phase `SPC Founder Fellowship · submit by 3 Aug 08:59`,
whose stored deadline matches SPC's official 2 August, 23:59 PT cutoff.

## Roles and authority

**Felix** owns the objective and retains authority over personal truth,
co-founder status, location/full-time commitments, disclosure, investment terms,
and submission.

**Codex** is the current executor. It can inspect the graph and repository,
research public requirements, draft, implement bounded improvements, run tests,
and record evidence. It cannot truthfully manufacture Felix's biography or make
institutional representations in his name.

**Boardy** is an external critic. Boardy challenged the commercial path, warned
that the recursive proof becomes gimmicky when it asks reviewers to admire the
process, identified the Founder Fellowship target, and scheduled a working
session with Felix.

## What the graph changed

The application objective was decomposed into five children:

- evidence-grounded draft — agent-actionable;
- recursive proof artifact — agent-actionable;
- founder facts and consequential choices — human-dependent;
- Boardy working session — human-dependent;
- final authorization and submission — human-dependent.

Only the coherent application objective is committed to the deadline phase. Its
children inherit the phase transitively through contribution edges.

## A real correction produced during the run

The phase UI's priority panel originally included subphases but only aims with a
direct phase commitment. This hid the human-dependent children of the committed
SPC objective—the decisions most likely to block submission.

Codex changed the list to traverse the committed aim subtree, added explicit
`via committed aim` labels, handled graph cycles, retained `human-dependent` as
the default filter, and loaded complete aim state on demand.

Verification:

- phase-priority logic and component tests: 6/6 pass;
- frontend TypeScript/Vue type-check: pass.
- application packet verifier: all current invariants pass. Run
  `node meta/applications/spc-founder-fellowship-2026/verify-packet.mjs` to check
  mission parents, deadline commitment, child links, human gates, exact route,
  answer limits, and the canonical artifact index.

The result is not merely a cleaner application document. The system became more
capable of exposing where human judgment is required in any deadline phase.

## Continuity test

A replacement executor should be able to:

1. open the application aim context;
2. recover both missions and the official deadline phase;
3. distinguish completed evidence from unsupported claims;
4. continue the agent-actionable draft and proof aims;
5. stop at the three human-dependent gates;
6. record verified outcomes back into the graph.

That is the product claim in its smallest testable form: the model may change;
the institution's purpose, boundaries, and evidence do not have to disappear
with its context window.

## Honest limit

This run demonstrates direction continuity and authority boundaries inside a
software project. It does not yet prove customer demand, economic repeatability,
or coordination of independently operated external agents. Those remain real
experiments rather than conclusions.
